# OpenAI Platform / ChatGPT Plugin Submission Package

This folder contains pre-configured artifacts for publishing the **Autonomous Issue Delivery Agency** to the OpenAI Plugin / GPT Store and Codex ecosystem:

- `openai-plugin.json`: Submission manifest descriptor.
- `chatgpt-instructions.md`: Ready-to-paste Custom GPT system prompt and configuration parameters.
- `test-cases.json`: Automated evaluation test cases.

## Submission Checklist
1. Verify developer identity and organization write access.
2. Ensure repository URLs are public and accessible.
3. Import the system instructions into Custom GPT / Codex Plugin Manager.
4. Run test cases defined in `test-cases.json`.
